# Synthetic data

Everything in `synthetic/` is generated by `scripts/generate_synthetic_docs.py`. Organisations,
people, NIC numbers, bank accounts and issuing bodies are **fictional**, and every page carries a
small "Synthetic test document" notice. `ground_truth/` mirrors `synthetic/` with one JSON file
per document holding the values extraction must produce (Plan 14.2).

## Things to know when building the pipeline

- **Spreadsheets have a title block.** The header row is row 5 on every sheet (`pd.read_excel(..., header=4)`), just
  as real HR-system exports do. Find the header by matching column names rather than hard-coding the row.
- **Read ID columns as text.** pandas turns NIC and account numbers into integers unless you pass `dtype=str`.
  Presidio has to see them as strings to mask them.
- **R07 needs an effective-dated minimum wage.** The national minimum was LKR 27,000 until 31 Dec 2025 and
  LKR 30,000 from 1 Jan 2026. The payroll crosses that date (lowest basic is 29,500 before, 31,500 after). A single
  `MIN_MONTHLY_WAGE_LKR` would wrongly flag Oct–Dec 2025, so store `(effective_from, amount)` pairs.
- **Simulated photos are not a substitute for real ones.** Plan 14.1 still requires at least 10 real phone photos
  of printed pages. Print a few of these PDFs and photograph them.
- **The planted blur is a guess until Document AI sees it.** If the fire certificate's expiry date still comes back
  above 0.70 confidence, raise `blur=` for that document in `scripts/synthetic/build.py` and regenerate.

## Regenerating

```bash
cd backend
uv sync --group data
uv run --group data playwright install chromium   # first time only
uv run --group data python ../scripts/generate_synthetic_docs.py --demo-date 2026-10-18
```

If the demo date moves, pass the new `--demo-date` so the boiler certificate still expires 23 days after it.
Chromium stamps each PDF with a creation time, so regenerating changes every file's SHA-256 (and busts the
Document AI response cache). Generate once, commit, and regenerate only on purpose.
